# ExamInsight - Exam Preparation Portal

ExamInsight is a comprehensive, web-based platform designed to help students prepare for competitive examinations through interactive mock tests, syllabus tracking, and personalized performance dashboards.

## 🚀 Features

* **Mock Exam Engine**: Interactive testing interface with a database of questions for subjects like JEE Physics.
* **Performance Dashboard**: Track study progress with visual goal bars and activity logs.
* **Syllabus Tracker**: Stay organized by monitoring your progress across various exam topics.
* **Resource Library**: Access and download study materials, such as advanced physics solutions and revision tests.
* **Study Calendar**: A dedicated section to manage study schedules and important exam dates.
* **Responsive Design**: A mobile-friendly interface featuring a dedicated navigation menu for smaller screens.

## 🛠️ Tech Stack

* **HTML5**: Semantic structure for the portal sections including Home, Syllabus, and Dashboard.
* **CSS3**: Custom styling using CSS variables with a professional gold and blue color palette (`#ae7743`, `#1e40af`).
* **JavaScript (Vanilla)**: Powers the exam logic, question database, navigation switching, and UI animations.

## 📁 Project Structure

* `index.html`: The main entry point containing the structure for all portal sections.
* `style.css`: Contains global styles, theme variables, and responsive media queries.
* `script.js`: Manages the mock exam database, interactive UI elements, and navigation logic.

## 📝 Usage

* **Taking a Mock Test**: Navigate to the "Mock Exam" section to begin interactive quizzes like JEE Physics.
* **Checking Progress**: Visit the "Dashboard" to view recent activity, such as completed exams and scores.
* **Mobile Navigation**: On mobile devices, use the hamburger menu to switch between different study sections.
