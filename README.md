# ExamReady: simple HTML, CSS and JavaScript

## Technology stack
- HTML: page structure
- CSS: responsive styling
- Vanilla JavaScript: navigation, exam logic and progress calculations
- Browser localStorage: save demo progress on this device

No React, Node.js backend, Python, or database is required for this demo.

## Run
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Optional: use Visual Studio Code with the Live Server extension and select **Open with Live Server**.

## Included
Dashboard, mock exam with answer explanations, syllabus checklist, learning resources, demo profile, privacy policy template, terms template and favicon.

## Limitations
Data stays in one browser and does not sync across devices. The profile form is not secure authentication. Do not use this for real student accounts. To support multiple students, add a simple backend such as PHP + MySQL later, with secure authentication and user-specific data access. Review the legal templates before publishing.
